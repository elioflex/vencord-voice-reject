Settings
Command
Command sent when you click a reject button. The user id is appended for you; optionally place {userId} or {username} yourself to put it somewhere else in the command.
Delay Seconds
Seconds before the sent command is deleted — a plain number like 1 or 2 (0 = keep it).
1. Open the text channel the command should be sent to. 2. Press “Use #channel for …” below. That is the whole setup — the command and the delay are optional, and their defaults already work.
Every server is configured separately: give one its own command and the others keep the default.
Prefer to be explicit, or configuring a channel you cannot open? Paste its channel id into the “Reject channel” box of any server below instead.
